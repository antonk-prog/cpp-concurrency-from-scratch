# Курс «Многопоточность в C++»

Практический курс по многопоточности и конкурентности в C++17 на основе
книги Энтони Уильямса «C++ Concurrency in Action», 2-е изд. (2020).

Этот курс — выжимка ключевых идей и практик из книги, дополненная примерами и лабораторными работами. Он поможет не просто прочитать теорию, а закрепить результат через практику. Для каждой лабораторной работы предусмотрены две подсказки, которые можно открывать последовательно, а в конце — посмотреть готовое решение.

Курс строится из модулей по главам книги. Каждый модуль = одна лекция
(`modules/module-NN-slug/README.md`) и набор лабораторных
(`modules/module-NN-slug/labs/lab-NN-MM-slug/`).
