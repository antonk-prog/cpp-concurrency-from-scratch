AUTHORING — как авторить этот курс
Документ для автора (человека) и контрибьюторов, генерирующих контент.Студентам он не нужен.

Предпосылки
opencode с плагином skills (скиллы course-author, course-review —в .opencode/skills/, они коммитятся в репозиторий).
Текст глав книги — в source/ (в .gitignore, вне git по причинамавторских прав).
Модель значения не имеет; пайплайн работает с любой.
Инициализация (один раз)
Запусти /common-ground (full flow). При surface-фазе используйкак отправную точку:
ESTABLISHED [stated]: второе издание (2020); C++17 без C++20 API;аудитория знает C++; memory ordering/lock-free включены полностью;язык курса русский; текст книги не цитируется, source/ вне git.
WORKING [assumed]: лекция 1000–2000 слов; 1–3 лабы на модуль по 30–60 мин;две подсказки (направление → механизм без кода).
OPEN [uncertain]: нужен ли финальный capstone-проект; лицензиярепозитория; сslug'и папок — уточни и продвинь тиры.
Скилл course-author, команда: «Этап 0 — построй карту курса пооглавлению из source/ и заполни корневой README.md».
Проверь карту руками. На этом этапе дешевле всего чинить перекосы(все лабы «напиши с нуля», слишком ранние atomic, задачи-не-задачи).
Цикл на модуль
Новая сессия opencode. /common-ground --check.
course-author: «Модуль N. Источник: source/<глава>.md. Этап 1 — план».→ появляется PLAN.md с «Допущениями модуля» (surface-фаза).
Правишь план руками или в диалоге. Говоришь «ок».
course-author: «Этап 2, начни с лекции» → «дальше» на каждую лабу.Агент сам компилирует, запускает и гоняет TSan перед выдачей.
course-review в НОВОЙ сессии: «review module N». Свежий контекст = свежиеглаза, тот же агент будет защищать своё.
Правки → повторный review → коммит. Один коммит = один модуль.
Гигиена
Не тащи в сессию главы сверх текущей — контекст дорог.
Если ответ агента «поплыл» — напомни секцию формата из скилла, а непереписывай скилл.
Решения, принятые в диалоге с агентом, — фиксируй в ground file(ESTABLISHED) и в PLAN.md. Чат — не память.
Перед релизом модуля: собери всё через CI (GitHub Actions: g++ -std=c++17-pthread, сборка всех starter/ и solution/, при желании TSan-job).
Запасной путь (без opencode)
Промпты из этого процесса работают и в веб-чате: системный промпт = телоскилла course-author; для выдачи файлов добавь формат маркеров=== FILE: путь === и распаковывай их в файлы.
