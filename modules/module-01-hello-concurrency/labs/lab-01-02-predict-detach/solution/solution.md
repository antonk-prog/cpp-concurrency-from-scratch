# Решение 1.2

## Что напечатает программа

Возможные варианты вывода (все реально достижимы):

```
Главный поток завершается
```

```
Фоновая задача отработала
Главный поток завершается
```

```
Главный поток завершается
Фоновая задача отработала
```

```
(пусто — ни одной строки)
```

Последний случай редок, но возможен: если оба потока не успели вывести ни одной
строки до завершения процесса.

## Почему недетерминировано

После `main` печатает свою строку и сразу возвращает `0` — это завершает весь
процесс вместе со всеми потоками, включая отсоединённый. Фоновый поток никто
не ждёт: `detach()` разорвал связь, и `join()` не вызывается.

Поэтому появление строки «Фоновая задача отработала» зависит от того, успеет ли
фоновый поток запуститься и выполнить `std::cout` до того, как процесс завершится.
Это решают планировщик ОС и относительная скорость потоков. На практике чаще
всего главный поток успевает завершиться первым, и фоновая строка не печатается.

## Корректна ли программа (есть ли UB)

Здесь **нет неопределённого поведения по памяти**: отсоединённый поток обращается
только к `std::cout` (глобальному объекту с корректным временем жизни на всё время
программы) и не трогает никакие локальные объекты из `main`. К тому же в этом
примере фоновый поток только один, так что нет даже гонки двух потоков за один
и тот же вывод.

Однако поведение **непредсказуемо**: какой именно из перечисленных вариантов
вывода получится, гарантировать нельзя. Для детерминированного результата нужно
было бы дождаться фонового потока через `join()` (см. лабу 1.1). Если бы фоновый
поток обращался к локальной переменной из `main`, завершение `main` уничтожило бы
эту переменную, и получилось бы обращение к уничтоженному объекту — вот это уже
был бы UB (рассмотрим в главах 2–3).
