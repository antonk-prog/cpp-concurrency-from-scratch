# Направление мысли

Поток — это выполнение отдельной функции. У каждой задачи должна быть своя
функция, которая принимает результат «наружу» через ссылку на локальную
переменную. Запускаешь поток так: `std::thread имя(функция, &переменная)`.

После запуска обоих потоков главному потоку остаётся только подождать их:
у каждого объекта `std::thread` вызови `join()`. Только после этого читай
значения переменных — к тому моменту потоки гарантированно закончили запись.
