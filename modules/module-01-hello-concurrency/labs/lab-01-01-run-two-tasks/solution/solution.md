# Решение 1.1

Запускаем два потока. Обрати внимание: аргументы функций потоков передаются
в конструктор `std::thread` по значению, поэтому ссылку на локальную переменную
нужно обернуть в `std::ref`, иначе функция получит копию и результат никуда
не запишется.

```cpp
std::thread sumThread(computeSum, n, std::ref(sum));
std::thread countThread(countMultiplesOfSeven, n, std::ref(count));
```

`std::ref(sum)` создаёт `std::reference_wrapper<int>`, который хранит ссылку
и при вызове функции разворачивается в неё. Без `std::ref` конструктор
`std::thread` скопировал бы `int sum`, функция записала бы в копию, а оригинал
остался бы нулём.

Затем оба потока ждём через `join()`. Читать `sum` и `count` можно только после
`join()` — к этому моменту оба потока гарантированно завершили запись. Именно
`join()` создаёт синхронизацию между потоками и главным потоком (формально это
проявление отношения happens-before, подробнее в главе 5).

Вывод:

```
Sum 1..100 = 5050
Multiples of 7 in 1..100 = 14
```
