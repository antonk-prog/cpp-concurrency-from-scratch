## Мотивация

Приложение скачивает данные с сервера и одновременно считает контрольную сумму
уже полученного файла. Эти две задачи независимы: пока одна ждёт сеть, другая
грузит процессор. Вместо того чтобы выполнять их строго по очереди, их можно
запустить в двух потоках — и не важно, сколько ядер на машине: каждая задача
выполняется сама по себе.

## Задача

В стартовом коде уже есть две функции-задачи `computeSum` и
`countMultiplesOfSeven`, а в `main()` — объявлены переменные `sum` и `count`.
Твоя работа — **дописать два места** (отмечены `TODO`):

1. Запустить два потока: один выполняет `computeSum`, другой —
   `countMultiplesOfSeven`. Каждому передай `n` и ссылку на свою переменную
   результата.
2. Дождаться завершения обоих потоков через `join()`.

После этого главный поток печатает итоги. Возьми `N = 100`. Логику самих
функций не меняй.

Ожидаемый вывод:

```
Sum 1..100 = 5050
Multiples of 7 in 1..100 = 14
```

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra task.cpp -o /tmp/lab_01_01`.
2. Ровно два потока, кроме главного: `std::thread sumThread` и
   `std::thread countThread`.
3. Результаты каждой задачи хранятся в отдельных переменных и передаются
   в функцию потока по ссылке.
4. Для каждого `std::thread` вызван `join()` до завершения `main`.
5. Вывод в точности:
   ```
   Sum 1..100 = 5050
   Multiples of 7 in 1..100 = 14
   ```
