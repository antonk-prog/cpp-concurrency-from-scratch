# Решение 1.3

## В чём баг

`std::thread worker` создаётся в `main`. Если `processData(value)` бросает
исключение (при `value < 0`), поток управления перескакивает на обработчик —
а `worker.join()` так и не выполняется. Затем при раскрутке стека у объекта
`worker` вызывается деструктор. Деструктор `std::thread` у **joinable**-потока
(того, для которого не вызван ни `join()`, ни `detach()`) вызывает
`std::terminate()`. Программа аварийно завершается.

## Как чиним — RAII-обёртка ThreadGuard

Гарантировать `join()` при любом исходе помогает класс-обёртка, которая
в деструкторе дожидается потока:

```cpp
class ThreadGuard {
public:
    explicit ThreadGuard(std::thread& t) : thread_(t) {}
    ThreadGuard(const ThreadGuard&) = delete;             // не копируется
    ThreadGuard& operator=(const ThreadGuard&) = delete;
    ~ThreadGuard() {
        if (thread_.joinable()) {
            thread_.join();                               // всегда ждём поток
        }
    }
private:
    std::thread& thread_;
};
```

Используется так:

```cpp
std::thread worker(doWork, value);
ThreadGuard guard(worker);   // деструктор guard вызовет worker.join()
processData(value);          // даже если бросит — guard дождётся потока
```

Ключевое свойство — RAII: деструктор `guard` срабатывает и в нормальном пути,
и при исключении (во время раскрутки стека). Поэтому `join()` выполнится
в любом случае, и `worker` никогда не будет уничтожен в joinable-состоянии.

Дополнительно проверка `joinable()` перед `join()` защищает от повторного
вызова `join()` (вызывать `join()` у завершённого потока — ошибка).

## Почему не `detach()`

`detach()` не решает задачу: он не ждёт завершения работы потока, а лишь
отсоединяет его. Тогда `main` мог бы завершиться раньше, чем поток закончит,
а обращение к данным из `main` стало бы гонкой/UB. Нам нужно именно
**дождаться** потока — отсюда `join()`.

## Проверка

- `/tmp/lab_01_03 42` → печатает «Обработка данных: 42», завершается кодом 0.
- `/tmp/lab_01_03 -1` → печатает «Ошибка: неверный параметр», завершается
  кодом 1. Без `terminate`, поток дождались.
