# Лаба 10.1. Подсчёт посещений через transform_reduce — средняя
Модуль: 10. Алгоритмы параллельных вычислений
Тип: напиши с нуля

## Мотивация

В журнале сайта лежат миллионы строк; нужно посчитать, сколько раз открыли
каждую страницу. Работа делится на независимую обработку строк (парсинг) и
сведение результатов (объединение карт). Это ровно задача для
`std::transform_reduce` с политикой `std::execution::par`: преобразование +
сведение за один проход, без гонок и без ручного управления потоками.

## Задача

С нуля реализуй подсчёт посещений страниц:

- комбинирующий функтор `combine_visits` с четырьмя перегрузками `operator()`
  (карта+карта, запись+карта, карта+запись, запись+запись);
- функцию `count_visits_per_page`, вызывающую
  `std::transform_reduce(std::execution::par, ...)`.

## Требования

1. `combine_visits` покрывает все четыре комбинации операндов
   (`visit_map_type`/`log_info`); объединение карт идёт по меньшей из двух карт
   (сначала `std::swap`, если левая меньше правой).
2. `count_visits_per_page` использует `std::transform_reduce` с политикой
   `std::execution::par`, начальным значением `visit_map_type()` и функцией
   `parse_log_line` в роли преобразования.
3. Результат совпадает с эталонным последовательным подсчётом (сверка в `main`).
4. Код компилируется без предупреждений; TSan не находит гонку за данные;
   программа завершается успешно (exit 0).

- Сведение идёт по меньшей карте (swap перед обходом).
- Результат `transform_reduce` равен эталонному (проверка в `main`).
