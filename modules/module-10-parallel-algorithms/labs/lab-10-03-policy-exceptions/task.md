# Лаба 10.3. Исключения с политиками — средняя
Модуль: 10. Алгоритмы параллельных вычислений
Тип: предскажи вывод

## Мотивация

Политики выполнения меняют поведение при исключении: если пользовательский
код внутри алгоритма бросает исключение, все стандартные политики вызывают
`std::terminate` — перехватить его нельзя. Обычный алгоритм без политики
просто распространяет исключение к вызывающему коду. Разница принципиальная.

## Задача

Программа с двумя режимами:

- **без аргумента** — `std::for_each` без политики, лямбда бросает
  `my_exception`, вызов обёрнут в `try`/`catch`;
- **с аргументом `--policy`** — `std::for_each(std::execution::seq, ...)`
  с той же бросающей лямбдой, также в `try`/`catch`.

1. **Предскажи вывод программы** в каждом режиме. Обоснуй: что сделает
   `try`/`catch` в первом случае и почему во втором исключение «не поймается».
2. Запусти оба режима и проверь предсказание.
3. В `solution/` добавь поясняющий вывод.

## Требования

1. Предсказание записано ДО запуска для обоих режимов.
2. Объяснено, почему с политикой неперехваченное пользовательское исключение
   приводит к `std::terminate` (и какое исключение алгоритм всё же может
   выбросить).
3. Программа в режиме по умолчанию завершается успешно (exit 0) и печатает
   `CAUGHT`.

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка и запуск:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o policy_exc
./policy_exc                # без политики
./policy_exc --policy       # с политикой seq (завершится аварийно)
```

## Чеклист самопроверки

- Предсказание сделано и проверено (оба режима).
- Причина `std::terminate` объяснена.
- Режим по умолчанию: `CAUGHT`, exit 0.
