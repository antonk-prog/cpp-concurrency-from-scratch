# Подсказка 2 — механизм, без кода

Ключевая разница в коде:

```text
std::for_each(v.begin(), v.end(), [](int) { throw my_exception(); });
// исключение распространяется -> catch сработает

std::for_each(std::execution::seq, v.begin(), v.end(),
              [](int) { throw my_exception(); });
// std::terminate -> catch НЕ сработает, процесс упадёт
```

Единственное исключение, которое вызов алгоритма с политикой может выбросить
сам, — `std::bad_alloc` (не хватило памяти на внутренние структуры).

Программа: режим по умолчанию оборачивает вызов в `try`/`catch` и печатает
`CAUGHT`; режим `--policy` делает то же самое, но с `std::execution::seq` —
предскажи, что напечатается (если вообще напечатается) и чем закончится
процесс.
