# Подсказка 2 — механизм, без кода

Вызов с политикой и без политики — разные перегрузки с разным контрактом:

```text
std::for_each(begin, end, f);          // порядок гарантирован
std::for_each(std::execution::seq,
              begin, end, f);          // порядок НЕ гарантирован
```

Политика `seq` не параллелит, но переводит алгоритм в «режим с политикой»,
где контракт на порядок заменён на «без перемежения в неопределённом порядке».
Реализация может, например, пройти элементы в другом направлении или
переставить этапы.

Проверка в программе: заполнить вектор через `for_each(seq)` и сравнить с
эталонной последовательностью 1..1000. Если совпало — это сработало на данной
реализации, но гарантии нет. Для гарантии — обычный `for_each` без политики.
