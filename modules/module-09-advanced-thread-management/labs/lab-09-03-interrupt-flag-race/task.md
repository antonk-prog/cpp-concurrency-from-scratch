# Лаба 9.3. Гонка за флаг прерывания
Модуль: 9. Усовершенствованное управление потоками
Тип: найди и почини

## Мотивация

Прерывание потоков — кооперативное: прерываемый поток проверяет флаг в точке
прерывания, а прерывающий поток этот флаг устанавливает. Флаг читает рабочий
поток (в цикле), а пишет другой поток — это классическая гонка за данные.
Программа может «работать» годами, а потом упасть на определённом
планировщике. ThreadSanitizer должен поймать гонку сразу.

## Задача

В стартовом коде `interrupt_flag` с обычным `bool`-флагом. Найди гонку за
данные и исправь её: флаг обязан быть атомарным. Проверь через
ThreadSanitizer, что гонка уходит и потоки корректно завершаются по прерыванию.

## Требования

1. Флаг в `interrupt_flag` — `std::atomic<bool>`; установка через `store(true)`,
   чтение через `load()`.
2. Логика не меняется: `interruption_point()` бросает `thread_interrupted`,
   если флаг установлен; `interruptible_thread` перехватывает его в обёртке.
3. Программа: несколько фоновых потоков крутятся в цикле, проверяя точку
   прерывания; `main` дожидается накопленной работы, затем прерывает их
   (сигнал повторяется, пока все потоки не подтвердят остановку) и
   присоединяет все потоки.
4. Код компилируется без предупреждений; TSan чист; программа завершается
   успешно (exit 0) и все потоки останавливаются по прерыванию.

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o interrupt
```

Проверка гонки (на решении должно быть чисто, на стартере — должна ловиться):

```
g++ -std=c++17 -pthread -fsanitize=thread -g -O1 main.cpp -o interrupt_tsan
./interrupt_tsan
```
