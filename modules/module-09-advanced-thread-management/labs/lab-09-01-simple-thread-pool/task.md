# Лаба 9.1. Простой пул потоков
Модуль: 9. Усовершенствованное управление потоками
Тип: напиши с нуля

## Мотивация

Создавать поток на каждую задачу дорого, а потоков слишком много — плохо.
Пул потоков решает это: фиксированное число рабочих потоков создаётся один
раз, задачи кладутся в очередь, и рабочие потоки выполняют их по одной.
Такой пул — фундамент для более сложных конструкций из лекции (ожидание
результатов, локальные очереди, перехват работы).

## Задача

С нуля реализуй простой пул потоков:

- фиксированное число рабочих потоков — `std::thread::hardware_concurrency()`;
- очередь задач (потокобезопасная, дана в стартовом коде);
- `submit(f)` — кладёт задачу в очередь;
- флаг `done` и корректное завершение: все потоки гарантированно
  присоединяются (RAII), в том числе при исключении в конструкторе;
- цикл рабочего потока: берёт задачу, выполняет; если задач нет —
  `std::this_thread::yield()`.

## Требования

1. Поля объявлены в правильном порядке: флаг `done` и очередь ДО вектора
   потоков, вектор ДО `join_threads`.
2. `submit()` упаковывает задачу в `std::function<void()>` и кладёт в очередь.
3. Конструктор создаёт `hardware_concurrency()` потоков; при исключении во
   время запуска устанавливает `done = true` и выбрасывает заново.
4. Деструктор устанавливает `done = true`; `join_threads` присоединяет все
   потоки до разрушения очереди.
5. Программа: `main` отправляет пулу известное число задач, каждая увеличивает
   атомарный счётчик и накапливает сумму; в конце проверяется, что все задачи
   выполнены и сумма верна.
6. Код компилируется без предупреждений; TSan не находит гонку за данные.
