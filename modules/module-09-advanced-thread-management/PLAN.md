# Модуль 9 — Усовершенствованное управление потоками — ПЛАН

## Допущения модуля

### Прогрессия (что разрешено)
- Всё из модулей 1–8 (карта курса актуальна). Ключевые опоры:
  - `std::thread`, `join`/`detach`, RAII-обёртки (модуль 2);
  - `std::mutex`, `std::condition_variable` (модули 3–4);
  - `std::packaged_task`, `std::promise`, `std::future`, `std::async` (модуль 4);
  - атомарные типы, `memory_order` (модуль 5);
  - потокобезопасная очередь из главы 6 (модуль 6: lab-06-01 fine-grained queue,
    интерфейсы `push`/`try_pop`/`wait_and_pop`);
  - `join_threads`, `hardware_concurrency()` (модуль 8);
  - `parallel_accumulate` (модуль 2, лаба 2.3).
- `std::thread_local` — новый примитив, вводится лекционно с полным пояснением
  (ground A011); для лаб — только там, где без него нельзя.
- `std::result_of` — C++17-API, допустим; в лекции пояснить, что это
  и зачем (вычисление типа возвращаемого значения).
- `join_threads` из модуля 8 используем напрямую (введён в главе 8).
- Запрещено всё из C++20+: `std::jthread`, `std::counting_semaphore`,
  `std::barrier`, `std::latch`, корутины, `std::format`.
- Ложное совместное использование (глава 8) не вводится: только краткое
  упоминание в контексте зачем локальные очереди (без разбора механики).

### Тематика (соответствие главе 9)
Лекция покрывает:
- 9.1 Пулы потоков:
  - 9.1.1 простейший пул потоков (фиксированное число рабочих, очередь задач,
    `submit`, флаг `done`, порядок объявления полей, исключения в конструкторе);
  - 9.1.2 ожидание завершения задач: `std::packaged_task`, `std::future`,
    move-only `function_wrapper`, `parallel_accumulate` на пуле, выбор размера блока;
  - 9.1.3 задачи, ждущие другие задачи: взаимная блокировка при ограниченном
    числе потоков, `run_pending_task()`, Quicksort на пуле;
  - 9.1.4 снижение конкуренции за очередь: локальные относительно потока
    очереди (`thread_local`), `std::queue<>` и `std::unique_ptr<>`;
  - 9.1.5 перехват работы (work stealing): очередь-обёртка над `std::deque`
    с `push`/`try_pop`/`try_steal`, пул с перехватом, кэш-эффекты;
- 9.2 Прерывание потоков:
  - 9.2.1 запуск и прерывание: интерфейс `interruptible_thread`,
    `thread_local interrupt_flag`, инициализация через `std::promise`;
  - 9.2.2 обнаружение прерывания: `interruption_point()`, исключение
    `thread_interrupted`;
  - 9.2.3 прерывание ожидания на `std::condition_variable`: две проблемы
    (исключения, гонка), решение с таймаутом `wait_for` и `notify_all`;
  - 9.2.4 прерывание ожидания на `std::condition_variable_any`: собственный
    `custom_lock`, почему здесь проще;
  - 9.2.5 прерывание других блокирующих вызовов: цикл `wait_for` для `std::future`;
  - 9.2.6 обработка прерываний: перехват `thread_interrupted`, обёртка `catch`
    в конструкторе `interruptible_thread`;
  - 9.2.7 прерывание фоновых задач при выходе из приложения: прерывать все
    потоки до ожидания, конкурентная обработка прерываний.

### Список лаб (тип, название, суть, чему учит)

1. **lab-09-01-simple-thread-pool (напиши с нуля, средняя)**
   - Суть: реализовать простой пул потоков: фиксированное число рабочих
     (`hardware_concurrency()`), потокобезопасная очередь задач, `submit()`,
     корректное завершение (флаг `done`, join всех потоков в деструкторе,
     в т.ч. при исключении в конструкторе).
   - Чему учит: паттерн «пул потоков», цикл рабочего потока, гарантированное
     завершение и освобождение ресурсов, почему очереди/флаг объявляются до
     вектора потоков.
   - Прогрессия: `std::thread` (м2), mutex/condvar/queue (м3–4, м6),
     `std::atomic<bool>` (м5).

2. **lab-09-02-task-waits-task (предскажи вывод, сложная)**
   - Суть: пул с фиксированным числом потоков, задача, которая отправляет
     подзадачу в тот же пул и ждёт её результат через `.get()` внутри себя.
     Предсказать, завершится ли программа; объяснить механизм взаимной
     блокировки (все рабочие потоки ждут задачи, которые не запланированы)
     и способ исправления (`run_pending_task()`).
   - Чему учит: классическая ловушка «задача ждёт задачу» в пуле с
     ограниченным числом потоков; почему `std::async` этим не страдает;
     как помогает выполнение задач во время ожидания.
   - Прогрессия: пул из лекции/лабы 9.1, `std::future` (м4).

3. **lab-09-03-interrupt-flag-race (найди и почини, средняя)**
   - Суть: в стартовом коде `interrupt_flag` и фоновый цикл с точкой прерывания;
     флаг — обычный `bool`, пишется из `interrupt()`, читается из
     `interruption_point()` → гонка за данные, ловится TSan. Починить:
     `std::atomic<bool>`; проверить, что поток корректно завершается по прерыванию.
   - Чему учит: гонку за флаг прерывания, зачем атомарность в кооперативном
     прерывании, аккуратность `thread_local`-состояния.
   - Прогрессия: `std::atomic` (м5), `std::thread` (м2), `std::promise`/`future` (м4).

## Заголовки лекции (README.md) с 1–2 фразами содержания

1. **Зачем это нужно** — почему пул потоков вместо потока на каждую задачу;
   почему нужен сигнал остановки долгоиграющему потоку.
2. **Простейший пул потоков (9.1.1)** — фиксированное число рабочих, очередь
   задач, `submit`, флаг `done`, порядок объявления полей, исключения.
3. **Ожидание завершения задач (9.1.2)** — `packaged_task`/`future`, move-only
   `function_wrapper`, `parallel_accumulate` на пуле, размер блока.
4. **Задачи, ждущие другие задачи (9.1.3)** — взаимная блокировка,
   `run_pending_task()`, Quicksort на пуле.
5. **Снижение конкуренции за очередь (9.1.4)** — `thread_local` локальные
   очереди, `std::queue<>`, `std::unique_ptr<>`.
6. **Перехват работы (9.1.5)** — work stealing: очередь над `std::deque`,
   `try_steal` с конца, кэш-эффекты, пул с перехватом.
7. **Прерывание потоков: зачем и как (9.2)** — кооперативное прерывание,
   `thread_local interrupt_flag`, `interruptible_thread`.
8. **Обнаружение прерывания (9.2.2)** — `interruption_point()`, исключение
   `thread_interrupted`.
9. **Прерывание ожидания на условной переменной (9.2.3)** — две проблемы,
   решение `wait_for` + `notify_all`.
10. **Прерывание ожидания на `condition_variable_any` (9.2.4)** — `custom_lock`,
    почему проще.
11. **Прерывание других блокирующих вызовов (9.2.5)** — цикл `wait_for`
    для `std::future`, цена таймаутов.
12. **Обработка прерываний (9.2.6)** — перехват исключения, обёртка `catch`
    в конструкторе.
13. **Прерывание фоновых задач при выходе (9.2.7)** — пример поиска/индекса,
    прерывать всех до join.
14. **Типичные ошибки** — пул без join; задача ждёт задачу; неатомарный флаг;
    висячий указатель на флаг прерывания; гонка в interruptible_wait.
15. **Шпаргалка** — таблица: приём, где применяется, что даёт.
