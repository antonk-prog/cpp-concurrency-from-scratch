# Лаба 2.2. Владение потоком: scoped_thread — средняя
Модуль: 2. Управление потоками
Тип: допиши TODO

## Мотивация

Простая RAII-обёртка `thread_guard` хранит `std::thread` **по ссылке**: она
дожидается потока в деструкторе, но сам поток всё равно живёт в `main`.
Если `thread_guard` каким-то образом переживёт поток или у объекта появятся
две копии, легко ошибиться. Надёжнее, чтобы обёртка **владела** потоком:
тогда она сама хранит `std::thread` и гарантирует его завершение в своём
деструкторе. Такой класс называется `scoped_thread` — а заодно это хороший
повод разобраться с передачей владения потоком через перемещение.

## Задача

В стартовом коде есть функция `doWork` и недописанный класс `scoped_thread`.
Допиши недостающие части (отмечены `TODO`):

1. Конструктор `scoped_thread`, принимающий `std::thread` и владеющий им
   (перемести поток в член `t`). Объяви его `explicit`.
2. Удали конструктор копирования и оператор копирующего присваивания
   (`= delete`) — `scoped_thread` нельзя копировать.
3. Деструктор `scoped_thread`: если `t` joinable — вызови `t.join()`.
4. В `main`: напиши функцию `makeWorker()`, которая создаёт и **возвращает**
   `std::thread` (поток, выполняющий `doWork` с переданным значением),
   и используй её результат для создания `scoped_thread`.

Логику `doWork` не меняй. Программа должна выводить результат работы потока
и корректно завершаться (без `terminate`).

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_02_02`.
2. `scoped_thread` владеет `std::thread` по значению (член `std::thread t;`).
3. Конструктор `scoped_thread` — `explicit`, перемещает поток в член.
4. Копирование `scoped_thread` запрещено (`= delete`).
5. Деструктор `scoped_thread` вызывает `join()`, если поток joinable.
6. `makeWorker()` возвращает `std::thread` (перемещая владение наружу).
7. Программа печатает результат и завершается кодом 0, без `terminate`.

## Стартовый код

Один файл `main.cpp` с заготовкой `scoped_thread` и `main`. Собери:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_02_02
```

## Чеклист самопроверки

- [ ] Программа компилируется с `-Wall -Wextra` без замечаний.
- [ ] Результат работы потока выводится.
- [ ] Программа завершается корректно, без сообщения про `terminate`.
- [ ] Попытка скопировать `scoped_thread` даёт ошибку компиляции.
- [ ] `makeWorker()` возвращает `std::thread`, а не принимает готовый.
