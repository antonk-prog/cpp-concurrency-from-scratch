# Лаба 2.3. Параллельное суммирование — сложная
Модуль: 2. Управление потоками
Тип: напиши с нуля

## Мотивация

Однопоточный `std::accumulate` считает элементы строго по очереди — на
многоядерной машине время растёт линейно с размером данных. Ту же задачу можно
разбить на независимые блоки и суммировать их параллельно: каждый поток считает
свой кусок, главный поток складывает частичные результаты. Это простейший
пример **параллелизма данных** — и отличная демонстрация управления группой
потоков из главы 2.

## Задача

Напиши функцию `parallel_accumulate(Iterator first, Iterator last, T init)`,
которая суммирует диапазон `[first, last)` в несколько потоков и возвращает
итог. Используй стратегию из главы 2:

1. Если диапазон пуст — верни `init`.
2. Вычисли число потоков: `max_threads` из расчёта минимального размера блока
   (возьми `min_per_thread = 25`), ограничь сверху `std::thread::hardware_concurrency()`
   (если вернёт 0 — возьми 2). Итоговое число потоков —
   `min(hardware, max_threads)`.
3. Разбей диапазон на блоки по `block_size = length / num_threads`.
4. Запусти `num_threads - 1` потоков (последний блок считает сам `main`),
   каждый пишет результат в свою ячейку `std::vector<T> results` через `std::ref`.
5. `join()` все потоки, сложи частичные результаты с `init`.

В `main` продемонстрируй работу на диапазоне целых чисел от 1 до N (например,
`N = 1'000'000`): создай вектор, заполни его, выведи `parallel_accumulate`
и сверь с однопоточным `std::accumulate`. Результаты должны совпасть.

Используй: `std::thread`, `std::vector<std::thread>`, `std::ref`,
`std::thread::hardware_concurrency()`, `std::accumulate`, `<numeric>`,
`<thread>`, `<vector>`. Не меняй требования к итераторам: используй как минимум
однонаправленные итераторы (`std::distance`, `std::advance`).

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_02_03`.
2. Функция `parallel_accumulate` — шаблон с итераторами и типом `T`.
3. Число потоков ограничено `hardware_concurrency()` (с запасом 2 при 0).
4. Каждый поток пишет результат в отдельную ячейку `results` через `std::ref`.
5. Все потоки `join()`-ятся до возврата из функции.
6. Результат `parallel_accumulate` совпадает с однопоточным `std::accumulate`.
7. В `main` есть демонстрация на векторе с проверкой совпадения.

## Стартовый код

Стартового кода нет — пиши с нуля в файле `main.cpp`. Собери:

