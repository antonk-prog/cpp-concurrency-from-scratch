# Механизм (без кода)

- Поток 1: `std::thread t1(incrementAndSet, step, std::ref(counter));`
  Без `std::ref` не скомпилируется (rvalue в `int&`). `step` можно передать
  по значению (копия числа — ок).
- Поток 2: `std::thread t2(consume, std::move(p));` — после этого `p` пуст,
  потому что владение перемещено. Функция `consume` принимает
  `std::unique_ptr<int>` по значению — перемещение в параметр происходит
  автоматически.
- Не забыть `t1.join()` и `t2.join()` перед чтением `counter` и проверкой `p`.
