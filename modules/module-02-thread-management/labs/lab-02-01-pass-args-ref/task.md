# Лаба 2.1. Передача аргументов в поток
Модуль: 2. Управление потоками
Тип: напиши с нуля

## Мотивация

Поток редко бывает полностью автономен: ему нужно передать данные, а результат —
вернуть «наружу». Но конструктор `std::thread` копирует аргументы, поэтому просто
передать переменную по ссылке не выйдет — нужно явно сказать, что мы хотим
ссылку (`std::ref`) или перемещение (`std::move`). Без этого код либо не
скомпилируется, либо молча обновит копию, а не оригинал.

## Задача

Напиши программу, которая запускает **два** потока, и каждый демонстрирует
один из двух способов передачи аргументов:

1. **Поток 1 — запись по ссылке.** Функция `incrementAndSet(int step, int& target)`
   прибавляет `step` к `target` и возвращает `void`. Запусти этот поток так,
   чтобы он изменил именно твою переменную `counter` (передай её через
   `std::ref`). После `join()` напечатай `counter`.

2. **Поток 2 — передача владения.** Функция `consume(std::unique_ptr<int>)`
   выводит значение, на которое указывает переданный указатель (владение
   переходит в поток). Создай `std::unique_ptr<int>` со значением, например,
   `99`, и передай его в поток через `std::move`. После `join()` проверь, что
   указатель в `main` стал пустым (`p == nullptr`), и выведи об этом сообщение.

Обе функции напиши сам. Используй `std::thread`, `join()`, `std::ref`, `std::move`,
`std::unique_ptr`, `<memory>`.

Ожидаемый вывод (числа — примерные, главное — факт):

```
Counter after thread 1: 5
Pointer in main is now null: true
Consumed value: 99
```

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_02_01`.
2. Поток 1 изменяет `counter` через `std::ref`; без `std::ref` код не собирается
   (нельзя передать rvalue в `int&`) — это нормальное требование, а не лазейка.
3. Поток 2 принимает `std::unique_ptr<int>` **по значению**; передаётся через
   `std::move`, после передачи `p` пуст.
4. Для каждого потока вызван `join()` до конца `main`.
5. Вывод показывает: обновлённый `counter`, пустой указатель после передачи,
   значение, полученное в потоке.

## Стартовый код

Стартового кода нет — пиши с нуля в файле `main.cpp`. Собери:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_02_01
```
