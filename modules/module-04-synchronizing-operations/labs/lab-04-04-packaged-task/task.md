# Лаба 4.4. Задача через std::packaged_task
Модуль: 4. Синхронизация конкурентных операций
Тип: напиши с нуля

## Мотивация

`std::packaged_task` — это «упакованная» задача: вызываемый объект, который при
вызове сохраняет свой результат в связанный фьючерс. Это строительный блок для
пулов потоков и очередей задач: поток, который должен выполнить работу, просто
вызывает упакованную задачу, а тот, кто ждёт результат, забирает его из
фьючерса. В отличие от `std::async`, здесь ты сам решаешь, **где и когда**
запустится задача.

## Задача

Напиши с нуля программу (файл `main.cpp`), которая демонстрирует работу
`std::packaged_task`:

1. Есть обычная функция, считающая квадрат числа: `square(int)`.
2. Упакуй её в `std::packaged_task<int(int)>`. **До** запуска получи у задачи
   связанный фьючерс и сохрани его.
3. Выполни задачу в отдельном `std::thread`, передав число `7`. Забери
   результат через `future.get()` и напечатай его.
4. Есть функция, которая может бросить исключение: `checked_divide(int, int)`
   (деление на ноль — ошибка).
5. Упакуй её в `std::packaged_task<int(int, int)>` так же, и запусти с
   аргументами, приводящими к исключению. Убедись, что исключение выходит
   **из `future.get()`**, перехвати его и напечатай сообщение.

Используй: `std::packaged_task`, `get_future()`, `std::future`, `std::thread`,
`std::move`.

Ожидаемый вывод:

```
square(7) = 49
caught: division by zero
```

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_04_04`.
2. Для каждой задачи используется `std::packaged_task`; фьючерс берётся через
   `get_future()` **до** выполнения задачи.
3. Задача выполняется в отдельном потоке `std::thread`; поток корректно
   `join()`-ится.
4. Результат берётся через `future.get()`; исключение из второй задачи
   перехватывается из `get()`.
5. Программа печатает обе строки и завершается кодом 0.
