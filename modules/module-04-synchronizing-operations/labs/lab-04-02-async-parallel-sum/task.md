# Лаба 4.2. Параллельная сумма через async
Модуль: 4. Синхронизация конкурентных операций
Тип: напиши с нуля

## Мотивация

`std::async` — самый простой способ запустить независимую задачу «где-то» и
позже забрать результат через `std::future::get()`. Это естественная замена
ручному управлению потоками, когда важен только результат, а не сам поток.
Разбив суммирование на блоки, мы получаем параллельную версию `std::accumulate`
почти без низкоуровневого кода — и наглядно видим, как `get()` блокирует поток
до готовности.

## Задача

Напиши функцию `parallel_sum(const std::vector<int>& data, size_t num_tasks)`:

1. Если `data` пуст — верни `0`.
2. Разбей диапазон на `num_tasks` примерно равных блоков (последний блок
   может быть короче — учти остаток от деления).
3. Для каждого блока запусти `std::async(std::launch::async, суммирующая_лямбда,
   начало, конец)`, где лямбда считает сумму блока через `std::accumulate` и
   возвращает `long long`. Сохрани фьючерсы в `std::vector<std::future<long long>>`.
4. Собери результаты через `future.get()` и сложи их.

В `main` продемонстрируй работу: вектор `1..1000000` (заполни через
`std::iota`), посчитай `parallel_sum(data, 4)` и сверь с однопоточным
`std::accumulate`. Выведи оба значения и признак совпадения.

Используй: `std::async`, `std::launch::async`, `std::future`,
`std::vector<std::future<>>`, `std::accumulate`, `<future>`, `<numeric>`,
`<vector>`.

Ожидаемый вывод:

```
Sequential = 500000500000
Parallel   = 500000500000
Match: yes
```

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_04_02`.
2. Каждый блок суммируется в отдельной async-задаче с `std::launch::async`.
3. Результат каждого блока приходит через `std::future<long long>` и `get()`.
4. Учтён остаток от деления (последний блок — до конца вектора).
5. `parallel_sum` совпадает с однопоточным `std::accumulate` для `int`.
6. Программа выводит значения и `Match: yes`, завершается кодом 0.
