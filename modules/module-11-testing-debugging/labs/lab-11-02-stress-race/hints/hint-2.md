# Подсказка 2 — механизм, без кода

Счётчик становится атомарным:

```text
std::atomic<int> counter{0};
```

Инкремент — через `fetch_add` (или `++` на атомарной переменной):

```text
counter.fetch_add(1, std::memory_order_relaxed);
```

`relaxed` здесь достаточно: нам не нужен порядок между потоками, только
атомарность обновления. Проверка в главном потоке — `counter.load()`.

Больше ничего менять не нужно: структура стресс-теста (потоки, повторы,
проверка итога) остаётся. Убедись, что под TSan стартер ловит гонку, а
решение чистое.
