# Подсказка 1 — направление мысли

Тест разбит на четыре части: общая настройка (очередь), потоковая настройка
(сигнал «готов»), конкурентный код (после `go`), финальные проверки.

Обе задачи уже получили копию `shared_future` `ready` (общий сигнал `go`).
После `ready.wait()` задача должна выполнить СВОЮ операцию с очередью:

- `push`-задача — `q.push(42)`;
- `pop`-задача — `return q.pop();` (извлечь значение).

Почему `pop`-задача возвращает значение из лямбды? Потому что у
`std::future<int> pop_done` — тип `int`: результат извлекается в основном
потоке через `pop_done.get()`.
