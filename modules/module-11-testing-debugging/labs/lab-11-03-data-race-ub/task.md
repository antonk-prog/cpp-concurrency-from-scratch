# Лаба 11.3. Предскажи вывод при гонке — базовая
Модуль: 11. Тестирование и отладка многопоточных приложений
Тип: предскажи вывод

## Мотивация

Гонка за данными — неопределённое поведение: программа может выдать почти
любой результат, и этот результат может меняться от запуска к запуску.
Уметь заранее сказать «это UB, предсказать нельзя» — важнее, чем гадать
конкретное число.

## Задача

Программа: два потока без синхронизации пишут общую переменную `value`
(каждый — свой диапазон), главный поток после `join` печатает `value`.

1. **Предскажи, что напечатает программа.** Можно ли назвать конкретное число?
   Обоснуй: почему это не «3» и не «2», а неопределённое поведение.
2. Запусти программу несколько раз. Сравни предсказание с реальными выводами.
3. Объясни, почему «часто получается последняя запись» — не гарантия, а
   особенность конкретного железа/планировщика.

## Требования

1. Предсказание записано ДО запуска: «вывод недетерминирован, это UB».
2. Объяснено, что такое гонка за данные и почему результат непредсказуем.
3. Программа печатает значение и завершается успешно (exit 0).

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка и запуск (несколько раз!):

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o race_ub
./race_ub
./race_ub
./race_ub
```

## Чеклист самопроверки

- Предсказание сделано и проверено несколькими запусками.
- Ответ «UB, вывод недетерминирован» обоснован.
- Программа корректно завершается (exit 0).
