# Механизм (без кода)

- Поля: `std::map<std::string, std::string> entries_; mutable std::shared_mutex m_;`.
- `find`: `std::shared_lock<std::shared_mutex> l(m_);`, затем поиск в `entries_`,
  при отсутствии ключа — `return {};`.
- `update`: `std::lock_guard<std::shared_mutex> l(m_);`, затем `entries_[name] = entry;`.
- `mutable` — потому что `find` — `const`, а блокировка — техническая операция.
- Финальная проверка после `join()`: каждый ключ писателя обязан присутствовать
  с точным значением; иначе выведи сообщение об ошибке и верни `1`.
- Читатель не должен считать ошибкой пустой ответ: писатель мог не успеть
  записать ключ. Ошибка — только несовпадение значения, когда запись найдена.
