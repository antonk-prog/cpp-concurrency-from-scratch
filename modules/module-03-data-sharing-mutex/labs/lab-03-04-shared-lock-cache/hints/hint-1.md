# Направление мысли

Читатели не мешают друг другу, но писатель мешает всем. Значит, одному и тому
же мьютексу нужны два режима: общий (shared) — когда несколько читателей могут
входить одновременно, и монопольный (exclusive) — когда пишет только один поток.

Вспомни, какая RAII-обёртка берёт общую блокировку, а какая — монопольную.
Какой тип мьютекса поддерживает оба режима?
