# Грабли 3.4

## Взял `std::shared_mutex`, но блокируешь везде монопольно

Если `find` использует `lock_guard` вместо `shared_lock`, читатели выстраиваются
в очередь — выигрыша от shared-блокировки нет. Чтение — только через
`std::shared_lock`.

## Забыл `mutable` у мьютекса

`find` — `const`-метод; без `mutable` блокировка в нём не скомпилируется.
Мьютекс — техническое поле, `mutable` корректен.

## Путаешь, кто кого ждёт

Пока есть хоть один читатель, писатель ждёт; пока пишет писатель — ждут
читатели и другие писатели. Это гарантирует сам `std::shared_mutex`, ничего
дополнительно делать не нужно.

## Считаешь ошибкой пустой ответ читателя

Писатель мог ещё не успеть записать ключ — тогда `find` честно вернёт пустую
строку. Ошибка — только когда значение ЕСТЬ, но не совпадает с формулой.

## Делаешь финальную проверку до `join()`

Пока писатели ещё пишут, часть ключей может отсутствовать. Полную проверку
всех ключей выполняй после `join()`.
