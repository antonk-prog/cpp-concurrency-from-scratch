# Лаба 3.2. Гонка в интерфейсе стека
Модуль: 3. Совместное использование данных несколькими потоками
Тип: найди и почини

## Мотивация

Класс «потокобезопасен» на вид: все методы блокируют мьютекс. Но это не спасает,
если гонка заложена в самом интерфейсе. Классика — `top()` и `pop()` раздельно:
два потока могут оба пройти проверку «стек непуст», оба прочитать один и тот же
верхний элемент, а потом один элемент потерять. Такой баг проявляется редко
и очень коварен.

## Задача

Дан класс `threadsafe_stack` — «потокобезопасный» стек с интерфейсом как у
`std::stack`: отдельные `top()` и `pop()`. Каждый метод блокирует
мьютекс, но интерфейс раздельных вызовов создаёт гонку между `top()` и `pop()`.

Найди заложенную гонку и перепроектируй интерфейс, как показано в лекции модуля
3 (раздел «Минимальные примеры», потокобезопасный стек):

- замени `T top()` + `void pop()` на **единую** операцию `std::shared_ptr<T> pop()`,
  которая под одной блокировкой читает верхний элемент, удаляет его и возвращает
  результат;
- пустой стек — не UB, а исключение `empty_stack` (тип уже есть в стартовом коде);
- `push(T)` оставь, он тоже блокирует мьютекс;
- `empty()` из интерфейса убери: даже если он блокирует мьютекс, его результат
  мгновенно устаревает — между `empty()` и следующей операцией стек может
  измениться.

Программа должна: запустить несколько потоков, которые делают `push()` и `pop()`,
и после завершения не терять элементы (число успешных `pop()` с корректными
значениями должно соответствовать числу `push()`).

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_03_02`.
2. В интерфейсе стека **нет** отдельных `top()` и `pop()`; вместо них единый
   `std::shared_ptr<T> pop()`, который читает и удаляет под одной блокировкой.
3. `pop()` на пустом стеке бросает `empty_stack`, а не делает UB.
4. В интерфейсе нет `empty()`: проверка пустоты — только внутри `pop()`
   (через `empty_stack`).
5. Программа не теряет элементы: сумма извлечённых значений после всех
   `join()` равна сумме вставленных.

## Стартовый код

Один файл `main.cpp` с классом, где есть гонка. Собери и запусти несколько раз:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_03_02
/tmp/lab_03_02
```
