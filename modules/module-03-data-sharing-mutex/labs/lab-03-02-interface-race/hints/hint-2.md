# Механизм (без кода)

- Единый метод: `std::shared_ptr<T> pop()`. Под одним `lock_guard`:
  проверь `data_.empty()` → брось `empty_stack`; сделай
  `auto res = std::make_shared<T>(data_.top()); data_.pop(); return res;`.
  Чтение и удаление — один неделимый шаг.
- `empty_stack` — уже есть в стартовом коде, наследуйся от `std::exception`
  и переопредели `what()`.
- В `main`: заранее положи в стек известные значения (например, 1..N),
  запусти несколько потоков, каждый циклически зовёт `pop()`, ловит
  `empty_stack` (стек опустел — выходи из цикла) и суммирует извлечённое
  в общий счётчик. Сумма должна равняться сумме 1..N.
- `empty()` после появления единого `pop()` уже не нужен в цикле — но метод
  можно оставить как часть интерфейса.
