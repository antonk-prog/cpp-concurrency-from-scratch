# Направление мысли

Проблема не в самих методах, а в их сочетании. Посмотри на пару
`if (!empty()) { int v = top(); pop(); }` — между `empty()`, `top()` и `pop()`
другой поток может успеть изменить стек.

Подумай: какая единственная операция могла бы заменить всю эту тройку, чтобы
внутри неё стек был защищён целиком? Что она должна делать и возвращать?
