# Механизм (без кода)

- `std::unique_lock<std::mutex> lk(m, std::defer_lock);` — объект создан,
  мьютекс НЕ заблокирован.
- После локальной работы: `lk.lock();` — взяли блокировку; изменили
  `shared_total`; `lk.unlock();` — отпустили.
- `unique_lock` живёт до конца итерации и при выходе из неё больше ничем
  не владеет — это нормально.
- Ожидаемый итог: `kWorkers * kIterations * kLocalSum`
  = 4 * 2000 * 124750 = 998000000.
