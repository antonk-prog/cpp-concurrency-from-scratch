# Направление мысли

Локальная работа с общим состоянием не связана — мьютекс ей не нужен. Его нужно
удерживать только на коротком участке «слить локальный результат в общий».

Подумай, как сделать так, чтобы объект блокировки существовал заранее, но
мьютекс брался только в нужный момент, а потом сразу отпускался. Какой RAII-класс
позволяет отложить блокировку и снять её вручную?
