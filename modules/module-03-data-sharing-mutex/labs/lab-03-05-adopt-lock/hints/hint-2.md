# Механизм (без кода)

- `std::lock(from.m_, to.m_)` блокирует оба мьютекса одной операцией; при
  недоступности освобождает уже захваченные и ждёт весь набор.
- `std::lock_guard<std::mutex> g1(from.m_, std::adopt_lock);` — флаг
  `adopt_lock` говорит обёртке: «мьютекс уже захвачен, просто владей им
  и разблокируй в деструкторе».
- Второй такой же `lock_guard` — для `to.m_`.
- После этого можно безопасно менять балансы; деструкторы обёрток разблокируют
  оба мьютекса при любом исходе.
- В `main`: поток `t` в цикле по `i` переводит в направлении `(i+t)%2`,
  сумма перевода — `(i % 20) + 1`. Итоговый баланс — 100000.
