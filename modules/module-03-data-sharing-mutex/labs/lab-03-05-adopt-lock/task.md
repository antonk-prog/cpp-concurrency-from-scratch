# Лаба 3.5. Перевод между счетами без deadlock — средняя
Модуль: 3. Совместное использование данных несколькими потоками
Тип: допиши TODO

## Мотивация

Банковский перевод трогает два счёта — две защищаемые области, два мьютекса.
Если потоки блокируют их в разном порядке, возникает deadlock: каждый держит
один счёт и ждёт другой. Классическое решение — захватить оба мьютекса одной
операцией `std::lock`, а разблокировку поручить RAII-обёрткам с флагом
`std::adopt_lock`.

## Задача

В стартовом коде есть структура `Account` с балансом и мьютексом и функция
`transfer(from, to, amount)`. Допиши три места (TODO):

1. Заблокируй оба мьютекса одной операцией `std::lock(from.m_, to.m_)` —
   это исключает deadlock при любом порядке вызовов.
2. Оберни уже захваченные мьютексы в `std::lock_guard` с флагом
   `std::adopt_lock`, чтобы они разблокировались при любом исходе (в том числе
   при исключении).
3. В `main` запусти **4 потока**: каждый делает 1000 переводов, чередуя
   направление (чтобы упражнялись обе последовательности блокировки).
   После `join()` всех выведи суммарный баланс.

## Требования

1. Сборка без ошибок и предупреждений:
   `g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o /tmp/lab_03_05`.
2. `transfer` использует `std::lock(from.m_, to.m_)` + два `lock_guard`
   с `std::adopt_lock`.
3. Никаких явных `unlock()`; никаких `sleep`.
4. Ровно 4 потока по 1000 переводов в обе стороны, все `join()`-ятся.
5. Вывод ровно `Total balance: 100000` — баланс сохраняется, программа
   не зависает.
