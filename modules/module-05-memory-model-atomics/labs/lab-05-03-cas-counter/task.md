# Лаба 5.3. Атомарный счётчик через CAS-цикл
Модуль: 5. Модель памяти и атомарные операции
Тип: напиши с нуля

## Мотивация

`compare_exchange_strong` (CAS) — краеугольный камень атомарного программирования.
На нём строятся счётчики, битовые маски и структуры данных, у которых нет готового
атомарного оператора (например, нет `fetch_mul`). Умение писать CAS-цикл
необходимо для глав 7–9 (структуры без блокировок, пулы потоков).

## Задача

С нуля реализуй потокобезопасный класс `atomic_counter` на основе
`std::atomic<int>`, у которого инкремент, декремент и чтение выполняются
**через CAS-цикл**, а не через `fetch_add`/`++`/`--`. Затем используй счётчик
в нескольких потоках и проверь корректность.

## Требования

1. Реализуй `increment()`, `decrement()` и `value()`.
- `increment()`/`decrement()` используют цикл `compare_exchange_strong`
      (с перезагрузкой ожидаемого значения). Запрещено использовать
     `fetch_add`, `fetch_sub`, `++`, `--` и операторы `+=`/`-=`.
   - `value()` использует `load()`.
2. Все операции используют `std::memory_order_seq_cst` (по умолчанию) —
   для простоты. Обрати внимание, что достаточно и `relaxed`, но начинай
   с `seq_cst`.
3. Программа запускает 8 потоков; каждый поток `iterations` раз вызывает
   `increment()`, затем `decrement()`.
4. После `join()` всех потоков финальное значение счётчика равно 0
   (все приращения скомпенсированы).
5. Код компилируется без предупреждений; TSan не находит гонку за данные.
6. Дополнительно: объясни, почему цикл CAS корректен
   (перезагрузка `expected` при неудаче).
