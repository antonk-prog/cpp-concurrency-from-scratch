# Подсказка 1 — направление мысли

CAS-цикл строится по схеме «прочитай → вычисли → попробуй обновить → при неудаче
повтори»:

1. Прочитай текущее значение счётчика (через `load()`).
2. Вычисли желаемое новое значение (текущее ± 1).
3. Вызови `compare_exchange_weak(expected, desired)`.
4. Если вернулось `true` — успех, выходи.
5. Если `false` — переменную уже изменил другой поток, и `expected` был обновлён
   новым значением. Используй обновлённый `expected` и повтори с шага 2.

Вопрос для размышления: почему `compare_exchange_weak` (а не `strong`) удобен
в цикле, и что произойдёт при ложном сбое?
