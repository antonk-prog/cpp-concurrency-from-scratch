# Подсказка 2 — механизм, без кода

Для `increment()`:

```text
int expected = value_.load();
while (!value_.compare_exchange_weak(expected, expected + 1)) {
    // expected уже обновлён неудачной попыткой до актуального значения;
    // пробуем снова с новым expected
}
```

Для `decrement()` — та же схема, но с `expected - 1`.

Для `value()` — просто `return value_.load();`.

Почему это работает: `compare_exchange_weak` атомарно сравнивает текущее значение
с `expected` и, если они равны, записывает желаемое. Если другой поток успел
изменить счётчик между `load()` и `CAS`, сравнение не сойдётся, `expected`
обновится до актуального значения, и цикл повторится. Ложный сбой
`compare_exchange_weak` тоже приводит к `false` и повтору цикла — но это
безопасно, значение не теряется.

`compare_exchange_strong` здесь не обязателен: в цикле `weak` проще и быстрее
на платформах с ложным сбоем.
