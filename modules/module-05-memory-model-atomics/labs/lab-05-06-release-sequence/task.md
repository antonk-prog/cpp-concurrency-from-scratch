# Лаба 5.6. Партия через release sequence
Модуль: 5. Модель памяти и атомарные операции
Тип: допиши TODO

## Мотивация

Release sequence позволяет одному `release`-сохранению «достучаться» до
нескольких потребителей через цепочку операций чтения-изменения-записи.
Классика — партия задач: писатель публикует `N` элементов одним сохранением
счётчика, а несколько потребителей забирают их через `fetch_sub`. Второй
и последующие потребители читают значение, записанное не самим `store`,
а предыдущим `fetch_sub`, — и всё равно синхронизируются с писателем.

## Задача

В стартовом коде допиши два `TODO`: `publish()` должен опубликовать партию
элементов (`count.store(kCount, std::memory_order_release)`), а `claim()` —
забрать один элемент через `count.fetch_sub(1, std::memory_order_acquire)`.
Правильные теги обеспечивают видимость массива `items` всем потребителям.

## Требования

1. `publish()` заполняет `items[i] = i * 2`, затем делает
   `count.store(kCount, std::memory_order_release)`.
2. `claim()` возвращает `count.fetch_sub(1, std::memory_order_acquire)`.
3. Потребитель: при `v <= 0` останавливается, иначе обрабатывает элемент
   `items[v - 1]` и помечает его обработанным.
4. Каждый элемент обработан ровно один раз; программа печатает `OK`
   и завершается с кодом 0.
5. Код компилируется без предупреждений; TSan не находит гонок.
