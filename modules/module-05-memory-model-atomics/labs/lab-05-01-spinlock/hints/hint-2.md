# Подсказка 2 — механизм, без кода

Для `lock()`:

- вызывай `test_and_set()` в бесконечном цикле;
- выходи из цикла, только когда результат вызова — `false`;
- используй `std::memory_order_acquire` как аргумент упорядочения.

Для `unlock()`:

- вызови `clear()` с `std::memory_order_release`.

Почему `acquire` в `lock()` и `release` в `unlock()` — объясняется в лекции:
это пара захват-освобождение, которая гарантирует, что изменения защищённых
данных, сделанные до `unlock()`, станут видимы после `lock()` в другом потоке.
