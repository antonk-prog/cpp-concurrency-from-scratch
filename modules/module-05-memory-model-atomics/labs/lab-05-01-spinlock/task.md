# Лаба 5.1. Спин-блокировка на atomic_flag — базовая
Модуль: 5. Модель памяти и атомарные операции
Тип: допиши TODO

## Мотивация

Атомарные операции позволяют построить простую блокировку без обращения
к операционной системе. Такая блокировка (спин-блокировка, spinlock) держит
поток в активном ожидании, пока мьютекс не освободится. Это основа, на которой
строятся более сложные синхронизирующие примитивы, а её реализация напрямую
использует семантику захвата-освобождения.

## Задача

В стартовом коде допиши класс `spinlock_mutex` на основе `std::atomic_flag`
(методы `lock()` и `unlock()`), затем используй его для защиты общего счётчика
в нескольких потоках.

## Требования

1. `lock()` блокирует мьютекс, крутясь в цикле `test_and_set()`, пока флаг
   не был установлен этим потоком. Используй `std::memory_order_acquire`.
2. `unlock()` сбрасывает флаг. Используй `std::memory_order_release`.
3. Программа запускает 4 потока, каждый делает `increments` итераций,
   увеличивая общий счётчик под блокировкой.
4. После `join()` всех потоков финальное значение счётчика равно
   `4 * increments`. Если счётчик защищён корректно, оно всегда сходится.
5. Код компилируется без предупреждений.

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o spinlock
```

## Чеклист самопроверки

- `lock()`/`unlock()` используют атомарный флаг и корректные `memory_order`.
- Каждый `std::thread` присоединён через `join()` до разрушения.
- Финальный счётчик равен ожидаемому значению при многократных запусках.
- Нет гонки за данные (прогони с `-fsanitize=thread`).
