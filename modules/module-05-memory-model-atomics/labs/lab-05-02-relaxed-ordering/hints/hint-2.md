# Подсказка 2 — механизм, без кода

1. Перенеси установку флага в конец записи: сначала заполни весь массив `data`,
   и только потом вызови `ready.store(true, ...)`.

2. Установку флага пометь как операцию **освобождения**
   (`memory_order_release`), а ожидание флага в читателе — как операцию
   **захвата** (`memory_order_acquire`).

Тогда цепочка «происходит до» будет такой: запись `data` происходит до установки
флага (порядок в коде); установка флага (release) синхронизируется с его
ожиданием (acquire); ожидание происходит до чтения `data` (порядок в коде).
Значит, запись `data` происходит до чтения `data` — гонки нет.

`relaxed` можно оставить только там, где он не влияет на передачу данных
(например, для флага результата `ok` после `join()`).
