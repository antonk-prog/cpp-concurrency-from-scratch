# Грабли лабы 5.5

## Опубликовал указатель до инициализации полей

Если `published.store(p, release)` стоит раньше, чем заполнены поля `p`,
читатель может увидеть «полусобранный» объект. Сначала заполняй поля,
потом публикуй указатель.

## Использовал relaxed вместо acquire/release

`relaxed`-загрузка не гарантирует, что читатель увидит записи полей объекта —
это гонка за данные. Нужна пара release (у писателя) + acquire (у читателя).

## Использовал consume

`consume` в C++17 практически не реализуется компиляторами. Используй
`acquire` — это рекомендация стандарта.

## Разыменовал nullptr

Читатель обязан в цикле дождаться непустого указателя, а не читать поля
сразу: `p->id` при `p == nullptr` — неопределённое поведение.

## Читал published с разной семантикой в цикле и при проверке

Используй `acquire` во всех загрузках `published` (и в условии цикла,
и там, где берётся значение). Разнобой в тегах может привести
к непредсказуемому результату.
