# Подсказка 2 — механизм, без кода

Дай каждому потоку собственный счётчик, выровненный по отдельной строке кэша:

```text
struct item {
    alignas(std::hardware_destructive_interference_size) std::atomic<long> v;
};
std::vector<item> counters(threads);
```

Поток `i` увеличивает `counters[i].v` — у каждого своя строка кэша, обмена
между ядрами нет:

```text
ts.emplace_back([&, i] {
    for (long k = 0; k < n; ++k)
        counters[i].v.fetch_add(1, std::memory_order_relaxed);
});
```

`alignas` на каждый элемент (а не на начало массива) гарантирует, что счётчики
не попадут в одну строку кэша. Итоговое значение — сумма всех счётчиков;
в бенчмарке её считать не обязательно, важны времена.

Замерь три режима: один поток с общим счётчиком, несколько потоков с общим,
несколько потоков с собственными счётчиками. Лучшее из трёх повторов, `-O2`.
