# Подсказка 1 — направление мысли

Подумай, какие переменные в `find_element` разделяют несколько потоков:

- `result` (std::promise) — потокобезопасен внутри;
- `done_flag` — вот он и подозрительный.

`done_flag` читается в цикле (`!done_flag`) всеми потоками и пишется тем, кто
нашёл соответствие. Чтение и запись одного и того же неатомарного `bool` из
разных потоков без синхронизации — гонка за данные (UB). Программа может
работать «обычно», но TSan обязан это поймать.

Что нужно, чтобы обращение к переменной из нескольких потоков было
корректным? Сделать её `std::atomic<bool>` и обращаться через `load()` /
`store()`.
