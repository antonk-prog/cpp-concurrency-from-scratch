# Лаба 8.2. Неатомарный флаг остановки — средняя
Модуль: 8. Разработка конкурентного кода
Тип: найди и почини

## Мотивация

Параллельный поиск в лекции останавливает остальные потоки общим флагом
«найдено»: как только один поток нашёл соответствие, остальные прекращают
проверку. Флаг читают все рабочие потоки, а пишет тот, кто нашёл элемент.
Если флаг — обычный `bool`, это гонка за данные: программа может работать
«по чистой случайности» и ломаться недетерминированно.

## Задача

В стартовом коде параллельный `find` с общим флагом остановки, объявленным
как обычный `bool`. Найди ошибку и исправь её: флаг обязан быть атомарным.
Проверь через ThreadSanitizer, что гонка уходит.

## Требования

1. Флаг остановки — `std::atomic<bool>`; чтение в цикле — через `load()`,
   установка — через `store(true)`.
2. Логика поиска не меняется: вернуть первый найденный итератор или `last`,
   если элемента нет; исключения из рабочих потоков передаются через
   `std::promise`.
3. Программа: поиск значения в большом массиве, найденное значение должно
   располагаться так, чтобы несколько потоков успели работать одновременно.
4. Код компилируется без предупреждений; TSan чист; программа печатает
   позицию найденного элемента и завершается успешно (exit 0).

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o pfind
```

Проверка гонки (на решении должно быть чисто, на стартере — должна ловиться):

```
g++ -std=c++17 -pthread -fsanitize=thread -g -O1 main.cpp -o pfind_tsan
./pfind_tsan
```

## Чеклист самопроверки

- Нашёл, какое поле пишется одним потоком, а читается другими.
- Флаг стал атомарным; гонка ушла (TSan чист).
- Результат поиска корректен: найдена позиция искомого значения.
- Ранняя остановка работает: программа не ждёт обработки всего диапазона.
