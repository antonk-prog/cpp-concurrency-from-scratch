# Лаба 8.1. Параллельный for_each
Модуль: 8. Разработка конкурентного кода
Тип: напиши с нуля

## Мотивация

`std::for_each` применяет функцию к каждому элементу диапазона. Если элементы
независимы, работу легко разделить между потоками заранее: режем диапазон на
блоки, каждый поток обрабатывает свой блок, а исключения из рабочих потоков
передаём вызывающему коду через `std::future`. Такой алгоритм — простейший
образец распределения данных, рассмотренного в лекции.

## Задача

С нуля реализуй параллельную версию `std::for_each`:

- разбей диапазон на смежные блоки, число потоков — из
  `std::thread::hardware_concurrency()` (с ограничением по размеру диапазона);
- каждый поток обрабатывает свой блок через `std::packaged_task` и
  `std::future`;
- все потоки гарантированно присоединяются через RAII-обёртку `join_threads`
  (напиши её сам);
- исключения из рабочих потоков повторно выдаются в вызывающем потоке.

## Требования

1. Реализован класс `join_threads`: хранит ссылку на вектор `std::thread`,
   в деструкторе присоединяет все `joinable()`-потоки.
2. Реализована функция `parallel_for_each(first, last, f)`, применяющая `f`
   к каждому элементу ровно один раз.
3. Число потоков не превышает `hardware_concurrency()`, но и не больше
   количества блоков размера `min_per_thread = 25`.
4. Рабочие потоки создаются через `std::packaged_task<void(void)>` +
   `std::future<void>`; результат каждого блока получается через `get()`.
5. Обработка основного потока тоже включена (последний блок).
6. Код компилируется без предупреждений; TSan не находит гонку за данные;
   программа завершается успешно (exit 0), если все элементы обработаны.
