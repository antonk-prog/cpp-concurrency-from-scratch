# Подсказка 1 — направление мысли

Алгоритм похож на параллельную версию `accumulate` из лекции, но результат
рабочим потокам не нужен — нужно лишь применить функцию и передать возможные
исключения.

Ключевые шаги:

- вычислить `length`, при пустом диапазоне вернуться;
- выбрать число потоков: минимум из `hardware_concurrency()` и
  `(length + min_per_thread - 1) / min_per_thread`;
- разбить диапазон на смежные блоки по `block_size`;
- для каждого блока, кроме последнего, создать `packaged_task` и запустить
  в новом потоке;
- последний блок обработать в текущем потоке;
- присоединить все потоки — так, чтобы это произошло в любом случае,
  даже при исключении.

Подумай, кто гарантирует join, когда `f` бросает исключение в одном из
рабочих потоков или в последнем блоке.
