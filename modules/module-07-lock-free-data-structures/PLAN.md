# Модуль 7 — Конкурентные структуры данных без блокировок — ПЛАН

## Допущения модуля

### Прогрессия (что разрешено)
- Всё из модулей 1–6. Ключевая опора — **атомарные операции и модель памяти
  из главы 5** (`std::atomic`, `memory_order`, CAS, release sequences, барьеры),
  а также структуры данных главы 6 (очередь с детализацией блокировок —
  прототип для lock-free очереди).
- Concurrency TS (`std::experimental::atomic_shared_ptr`, листинги 7.9–7.10) —
  только лекционно (упоминание), в лабах не использовать (правило: для лаб —
  примитивы, которые гарантированно компилируются).
- Запрещено всё из C++20+: `std::jthread`, `std::counting_semaphore`,
  `std::barrier`, `std::latch`, корутины, `std::format`.

### Тематика (соответствие главе 7)
Лекция покрывает:
- 7.1 Определения: типы неблокирующих структур (obstruction-free / lock-free /
  wait-free), за и против структур без блокировок.
- 7.2 Примеры:
  - 7.2.1 lock-free стек: push/pop через CAS-цикл (листинги 7.1–7.3);
  - 7.2.2 управление памятью: утечки, подсчёт потоков в pop, список отложенного
    удаления (листинги 7.4–7.5);
  - 7.2.3 указатели опасности (hazard pointers) (листинги 7.6–7.8);
  - 7.2.4 подсчёт ссылок: shared_ptr, atomic_shared_ptr (TS), раздельные
    внутренний/внешний счётчики (листинги 7.9–7.13);
  - 7.2.5 применение модели памяти: ослабление seq_cst до acquire/release/relaxed
    (листинг 7.13);
  - 7.2.6 lock-free очередь: SPSC, MPSC, помощь другому потоку
    (листинги 7.14–7.22).
- 7.3 Рекомендации: seq_cst для прототипа, схема утилизации памяти,
  проблема ABA, циклы активного ожидания и помощь другому потоку.

### Список лаб (тип, название, суть, чему учит)

1. **lab-07-01-lock-free-stack (напиши с нуля, средняя)**
   - Суть: реализовать lock-free стек через CAS-цикл: `push()` (CAS по `head`),
     `pop()` (CAS с защитой от двойного извлечения), данные — `shared_ptr<T>`
     (безопасность при исключении). Утечка узлов допустима (это осознанное
     упрощение, обсуждается в лекции — управление памятью тема следующих лаб).
   - Чему учит: CAS-цикл, гонка `head` в push/pop, почему узел нужно готовить
     до публикации в `head`.
   - Прогрессия: `std::atomic<node*>`, CAS (глава 5).

2. **lab-07-02-publish-before-ready (найди и почини, средняя)**
   - Суть: в lock-free стеке `push()` публикует узел в `head` ДО заполнения
     его данных (пишет `data` после `head.store`) — другой поток может прочитать
     узел, пока push его пишет; data race ловится TSan. Починить: готовить узел
     полностью до публикации.
   - Чему учит: почему узел обязан быть готов до публикации в `head`
     (после публикации менять его нельзя).
   - Прогрессия: `std::atomic<node*>`, `shared_ptr` (глава 5).

3. **lab-07-03-aba-problem (предскажи вывод, сложная)**
   - Суть: дан lock-free стек с повторным использованием узлов (free list):
     извлечённые узлы возвращаются в «пул» и переиспользуются. Предсказать,
     где возникает проблема ABA, объяснить сценарий (шаги 1–7) и как защититься
     (счётчик ABA в объединённой структуре).
   - Чему учит: проблема ABA — одна из главных ловушек CAS-алгоритмов;
     почему «равное значение» ≠ «тот же объект».
   - Прогрессия: CAS, структура-счётчик в `std::atomic` (глава 5).

## Заголовки лекции (README.md) с 1–2 фразами содержания

1. **Зачем это нужно** — чем блокирующие структуры ограничивают конкурентность;
   когда lock-free оправдан (максимальная конкурентность, надёжность при
   падении потока).

2. **Определения (7.1)** — неблокирующие структуры: obstruction-free / lock-free /
   wait-free; что значит «прогресс гарантирован».

3. **За и против (7.1.4)** — причины использовать (конкурентность, надёжность)
   и плата (сложность, производительность атомарных операций).

4. **Lock-free стек (7.2.1)** — CAS-цикл в push; проблемы pop (висячий указатель,
   двойное извлечение); `shared_ptr` для данных (листинги 7.2–7.3).

5. **Управление памятью (7.2.2)** — почему узел нельзя удалить сразу;
   подсчёт потоков в pop; список отложенного удаления (листинги 7.4–7.5).

6. **Указатели опасности (7.2.3)** — идея, реализация, функции
   `get_hazard_pointer_for_current_thread` и утилизация (листинги 7.6–7.8).

7. **Подсчёт ссылок (7.2.4)** — `shared_ptr`/`atomic_shared_ptr` (TS);
   раздельные внутренний/внешний счётчики (листинги 7.9–7.13).

8. **Модель памяти в lock-free коде (7.2.5)** — ослабление seq_cst →
   acquire/release/relaxed; почему release в push и acquire в pop достаточно
   (листинг 7.13).

9. **Lock-free очередь (7.2.6)** — SPSC (просто), MPSC (сложности), помощь
   другому потоку (листинги 7.14–7.22).

10. **Рекомендации (7.3)** — seq_cst для прототипа; схемы утилизации памяти;
    проблема ABA; циклы активного ожидания и помощь другому потоку.

11. **Типичные ошибки** — CAS-цикл без перезагрузки expected; двойное
    извлечение узла; раннее удаление узла (UB); ABA; seq_cst там, где
    достаточно relaxed.

12. **Шпаргалка** — таблица: приём, где применяется, что даёт.
