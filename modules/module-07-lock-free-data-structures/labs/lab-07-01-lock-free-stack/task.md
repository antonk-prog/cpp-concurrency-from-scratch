# Лаба 7.1. Lock-free стек через CAS
Модуль: 7. Конкурентные структуры данных без блокировок
Тип: напиши с нуля

## Мотивация

Стек — самая простая структура для знакомства с lock-free программированием:
и `push()`, и `pop()` работают с одним атомарным указателем `head`. Всё, что нужно
для синхронизации, — операция сравнения-обмена (CAS): она атомарно проверяет,
что `head` не изменился с момента чтения, и обновляет его. Так два потока не могут
«перезаписать» изменения друг друга.

## Задача

С нуля реализуй `lock_free_stack<T>`:

- `push(data)` — создаёт узел, готовит его полностью, затем публикует в `head`
  через CAS-цикл (сравнение-обмен по `head`).
- `pop()` — извлекает узел через CAS-цикл (только один поток может извлечь
  конкретный узел), возвращает `std::shared_ptr<T>` с данными (или пустой
  `shared_ptr`, если стек пуст).

Упрощение: **утечка узлов допустима** — удалять извлечённые узлы не нужно
(это осознанный выбор для простоты; управление памятью — тема следующих
разделов).

## Требования

1. `push()` использует цикл `compare_exchange_weak` по `head`; при неудаче
   первый аргумент (`next`) обновляется автоматически, перезагружать `head`
   вручную не нужно.
2. Узел полностью готов (данные и `next`) до публикации в `head`.
3. `pop()` проверяет `head != nullptr` в условии цикла (пустой стек — пустой
   `shared_ptr`).
4. `pop()` использует CAS: два потока не могут извлечь один и тот же узел.
5. Данные в узле — `std::shared_ptr<T>` (безопасность при исключении).
6. Программа: несколько потоков кладут уникальные значения, несколько потоков
   извлекают; в конце собраны все значения ровно по одному разу (без потерь
   и дубликатов).
7. Код компилируется без предупреждений; TSan не находит гонку за данные.
