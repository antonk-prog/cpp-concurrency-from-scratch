# Подсказка 1 — направление мысли

Три метода должны работать по одному образцу: **взять блокировку → найти запись
по ключу → выполнить действие**. Разница только в типе блокировки и действии.

- Чтение (`value_for`) — `std::shared_lock`: несколько читателей могут входить
  параллельно.
- Запись (`add_or_update_mapping`, `remove_mapping`) — `std::unique_lock`:
  только один писатель.

Для изменяющих методов готовый помощник `find_entry_for` уже реализован.
В `value_for` (он `const`) поиск делается аналогично, но по `const`-данным.

Подумай, что вернуть/сделать, если запись не найдена (`it == data.end()`).
