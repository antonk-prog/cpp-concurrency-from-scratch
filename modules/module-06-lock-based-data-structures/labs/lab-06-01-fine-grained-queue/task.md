# Лаба 6.1. Почини гонку в очереди с детализацией блокировок
Модуль: 6. Конкурентные структуры данных с блокировками
Тип: найди и почини

## Мотивация

Очередь с детализацией блокировок (отдельные мьютексы для `head` и `tail`)
позволяет `push()` и `pop()` работать параллельно. Но у неё есть тонкое место:
один из указателей читается в операции извлечения без должной защиты, из-за
чего возникает гонка за данные. Такой баг не всегда проявляется на практике,
но по модели памяти это неопределённое поведение.

## Задача

В стартовом коде потокобезопасная очередь с детализацией блокировок
(два мьютекса, фиктивный узел). В ней заложена ошибка, из-за которой возникает
гонка за данные. Найди её и исправь, сохранив детализацию блокировок
(не своди к одному мьютексу на всю очередь).

## Требования

1. Очередь использует два мьютекса: `head_mutex` и `tail_mutex`.
2. Гонка за данные устранена: `push()` и `pop()` не обращаются к одним данным
   без общего упорядочивающего мьютекса.
3. Детализация блокировок сохранена: `push()` и `pop()` не сериализуются
   полностью.
4. Программа: несколько потоков кладут в очередь числа, несколько потоков
   извлекают; в конце все вставленные элементы должны быть извлечены ровно
   по одному разу.
5. Код компилируется без предупреждений; TSan не находит гонку за данные.

## Стартовый код

Файлы: `starter/main.cpp`.

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o fine_queue
```

Проверка гонки (на решении должно быть чисто):

```
g++ -std=c++17 -pthread -fsanitize=thread -g main.cpp -o fine_queue_tsan
./fine_queue_tsan
```
