# Подсказка 1 — направление мысли

Эстафетная блокировка держит блокировку **только одного узла** — «текущего».
Продвижение происходит так: взять блокировку следующего узла, снять блокировку
текущего, перейти на следующий. Передача владения блокировкой выполняется
перемещением `std::unique_lock` (например, `lk = std::move(next_lk)`).

`push_front` — простейшая операция: узел создаётся вне блокировки, затем под
`head.m` вставляется в начало (обновление `new_node->next` и `head.next`).

В `remove_if`, когда узел удаляется, `current` **не** сдвигается — нужно проверить
новый узел, вставший на место удалённого.
