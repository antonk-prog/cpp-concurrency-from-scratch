# Лаба 6.3. Список с эстафетной блокировкой — сложная
Модуль: 6. Конкурентные структуры данных с блокировками
Тип: напиши с нуля

## Мотивация

В конкурентной структуре данных итераторы STL бесполезны: итератор хранит
ссылку на внутренние данные, и при параллельных изменениях контейнера эта
ссылка может стать недействительной. Вместо итераторов операции обхода
встраивают в сам контейнер — `for_each`, `find_first_if`, `remove_if`.
Чтобы разные потоки могли работать с разными узлами, используют эстафетную
блокировку по узлам (мьютекс на каждый узел).

## Задача

С нуля реализуй потокобезопасный односвязный список с мьютексом на каждом узле
и четырьмя операциями: `push_front`, `for_each`, `find_first_if`, `remove_if`.

## Требования

1. Узел: `std::mutex m; std::shared_ptr<T> data; std::unique_ptr<node> next;`
   (поле `data` — `shared_ptr`, чтобы возвращать данные безопасно).
2. Голова — фиктивный узел `head` (без данных), создаваемый конструктором.
3. `push_front(value)` — добавляет элемент в начало списка.
4. `for_each(f)` — применяет `f` к каждому элементу списка.
5. `find_first_if(p)` — возвращает `shared_ptr<T>` первого элемента, где `p`
   истинно, или пустой `shared_ptr`, если такого нет.
6. `remove_if(p)` — удаляет все элементы, где `p` истинно.
7. Разные потоки могут одновременно работать с разными узлами списка
   (эстафетная блокировка по узлам).
8. Программа: несколько потоков добавляют элементы, несколько — параллельно
   обходят/ищут/удаляют; финальное состояние согласовано.
9. Код компилируется без предупреждений; TSan не находит гонку за данные.

## Стартовый код

Файлы: `starter/main.cpp` (каркас класса с TODO-заглушками).

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o threadsafe_list
```

## Чеклист самопроверки

- Каждая операция обхода продвигается по списку, не оставляя ни один узел
  без защиты в момент работы с ним.
- Порядок блокировок всегда один — взаимная блокировка невозможна.
- `remove_if` удаляет узел безопасно, не создавая гонку за его мьютекс.
- TSan чист; все операции согласованы.
