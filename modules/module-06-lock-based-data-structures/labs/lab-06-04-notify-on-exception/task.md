# Лаба 6.4. Пробуждение при исключении — средняя
Модуль: 6. Конкурентные структуры данных с блокировками
Тип: допиши TODO

## Мотивация

Потокобезопасная очередь с условной переменной (см. листинг 6.2 лекции)
будит `notify_one()` ровно одного ожидающего потребителя. Но что если этот
разбуженный поток бросит исключение, сохраняя элемент? Элемент останется
в очереди, а остальные ожидающие потоки так и не получат уведомления —
программа может «заснуть», хотя данные доступны. Такую ошибку легко не
заметить: она проявляется только при исключении и только когда ждут
несколько потоков.

## Задача

В стартовом коде дана очередь с условной переменной и приёмник `payload`,
перемещение-присваивание которого может бросить исключение. Допиши
`wait_and_pop(T& value)`: если сохранение элемента в `value` бросает
исключение, очередь должна разбудить следующего ожидающего — чтобы элемент,
оставшийся в очереди, не «потерялся» для ждущих потоков.

## Требования

1. `push()` кладёт элемент и будит одного ожидающего (`notify_one()`) — уже
   реализовано.
2. `wait_and_pop(value)` ждёт, пока очередь не опустеет, затем забирает
   элемент. Если присваивание элемента в `value` бросает исключение:
   - элемент очереди **не должен быть потерян** (остаётся в очереди);
   - следующий ожидающий должен быть разбужен (`notify_one()`);
   - исключение пробрасывается дальше (`throw;`), а не проглатывается.
3. Блокировка снимается RAII-обёрткой даже при исключении; прямых
   `lock()`/`unlock()` нет.
4. Программа: два потребителя ждут элемент, производитель кладёт один элемент,
   у первого потребителя сохранение бросает исключение. Второй потребитель
   должен получить тот же самый элемент **без** дополнительного `push()`.
5. Код компилируется без предупреждений (`-Wall -Wextra`); TSan не находит
   гонку за данные.

## Стартовый код

Файлы: `starter/main.cpp` (очередь + демонстрационная программа).

Сборка:

```
g++ -std=c++17 -pthread -Wall -Wextra main.cpp -o notify_on_exception
```

На стартовом коде программа печатает `BUG` (второй потребитель не разбужен)
и завершается с кодом 1. После правки — `OK` и код 0.

Проверка гонки:

```
g++ -std=c++17 -pthread -fsanitize=thread -g main.cpp -o notify_on_exception_tsan
./notify_on_exception_tsan
```
